Studio RD Black V2 — Premium no agendamento

BASE: ZIP de auditoria enviado anteriormente. Este pacote contém somente o patch incremental; NÃO substitua arquivos completos antigos porque seu projeto pode ter correções posteriores.

FUNCIONALIDADES
- Consulta assinatura ativa e saldo real na página do cliente.
- Checkbox para solicitar usar um corte RD Black no agendamento.
- Registra apenas a INTENÇÃO no banco, sem desconto antecipado.
- Mostra ao barbeiro selo RD Black Premium, saldo e intenção do cliente.
- Na conclusão, sugere ASSINATURA como forma de pagamento quando a intenção está marcada e há saldo atual. Barbeiro ainda pode escolher outro meio.
- Backend valida assinatura ativa, saldo e vigência na solicitação; revalida o saldo na conclusão pelo fluxo preexistente.

APLICAÇÃO (PowerShell, raiz do projeto)
1. Faça commit/back-up antes.
2. Extraia o PATCH na raiz ou copie ALTERACOES.patch para a raiz.
3. git apply --check .\ALTERACOES.patch
4. Se der certo: git apply .\ALTERACOES.patch
5. npm run db:generate
6. npm run typecheck
7. npm run build
8. Depois do deploy com backup e migrações revisadas, execute `npm run db:deploy` no ambiente de produção, ou confirme que o Railway o faz automaticamente.

- O patch foi validado contra o ZIP antigo. Como você tem alterações recentes, `git apply --check` pode falhar. Não force o patch, não substitua arquivos inteiros; será preciso adaptar os trechos à sua versão atual.
